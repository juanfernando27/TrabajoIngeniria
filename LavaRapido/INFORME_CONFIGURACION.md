## Instalación global en Windows

El script Configurar-Skills-Codex.ps1 instala las distribuciones locales en `%USERPROFILE%\.agents\skills\<nombre>\SKILL.md`. Esta es la ubicación de usuario que Codex utiliza para los proyectos de esa cuenta de Windows. El script conserva instalaciones existentes, revisa también la ubicación anterior .codex/skills y genera un informe con cada resultado.

Con los tres ZIP originales en Descargas, abre el proyecto en VS Code y ejecuta el script desde PowerShell.

```powershell
.\Configurar-Skills-Codex.ps1 -ZipDirectory "$env:USERPROFILE\Downloads"
```

Si tus archivos están en otra carpeta, pasa esa ruta a -ZipDirectory. Si descargaste únicamente el ZIP contenedor, extráelo y usa la carpeta que contiene impeccable-main.zip, skills-main.zip y remotion-main.zip. La instalación de Impeccable usa su CLI oficial con el proveedor codex y alcance global. Los hooks automáticos se dejan para el flujo de autorización de cada proyecto.

En Codex para VS Code, inicia sesión con ChatGPT y abre `/skills` para comprobar las entradas locales. Las skills de la cuenta y las carpetas del equipo tienen verificaciones independientes. El instalador de Windows se entrega revisado y requiere ejecutarse en ese equipo para confirmar sus rutas y permisos. improve-animations queda pendiente de revisión también en ese instalador. La consulta del catálogo desde la CLI de este entorno no pudo completarse por restricciones de escritura de su estado local. La estructura de los SKILL.md y las entradas guardadas se verificaron por separado.

## Cómo ejecutar la página

Extrae el proyecto en una carpeta nueva, abre la carpeta que contiene server.js y ejecuta los comandos siguientes desde PowerShell.

```powershell
npm.cmd ci
node server.js
```

Abre [http://127.0.0.1:3000](http://127.0.0.1:3000). La base se crea en data/lavarapido.sqlite. Detén y vuelve a iniciar el servidor para comprobar la persistencia.

Para editar la composición, abre otra terminal y ejecuta el bloque siguiente.

```powershell
Set-Location motion
npm.cmd ci
npm.cmd run dev
```

Para regenerar los medios integrados, ejecuta npm.cmd run render y npm.cmd run poster desde motion.
